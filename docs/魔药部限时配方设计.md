## 二、现状勘察（2026-09-22 核实）

### 2.1 药水现状：无合成管线
- 现有 4 种效果药全部为商店直购、`/使用` 直接生效：
  - 白鲜香精：+25 生命
  - 提神剂：+30 精力
  - 活力滋补剂：+30 魔力
  - 莫特拉鼠汁：+20 精神
- **项目不存在「配方 → 材料 → 酿造 → 产出」的合成管线**——这是魔药部玩法的核心空白。

### 2.2 材料现状（item_data.dart:413-500）
- 禁林产出共 9 种材料：
  - 普通 7 种：独角兽毛 / 银色鳞片 / 会发光的圆石 / 龙血 / 蛇的毒牙 / 八眼巨蛛毒液 / 凤羽
  - 稀有 2 种：曼德拉草叶 / 月长石粉（不进普通采集池，需特殊途径）
- 商店 59 种有价物品，不含上述材料（材料只能禁林获取）。

### 2.3 限时窗口参照：节庆系统（P9）
- `mixin_festival.dart:45` `celebrateFestival`：`festivalDueToday` 判定窗口触发 → 一次性结算 → 记档防重。
- 该「窗口触发 + 一次性结算 + 记档防重」模式可直接复用于限时配方窗口。

## 三、方案设计

### 3.1 限时窗口（每学期 3 个）
| 窗口 | 时间（复用 worldState.term） | 内容 |
|------|------------------------------|------|
| 开学季 | 9 月（term=first 首月） | 基础配方 3 个 |
| 圣诞季 | 12 月（term=first 末月） | 进阶配方 3 个 |
| 冲刺季 | 5 月（term=second 倒数第二月） | 高阶配方 3 个 |

- 窗口判定复用 `festivalDueToday` 同款日期判定逻辑，无新增时间字段。

### 3.2 配方草案（9 种）
| 配方 | 产出 | 消耗材料 | 效果档位 |
|------|------|----------|----------|
| 欢欣剂 | 欢欣药剂 | 独角兽毛×2 | +40 精神 |
| 清醒剂 | 清醒药剂 | 银色鳞片×2 | +40 精力 |
| 护心剂 | 护心药剂 | 龙血×2 | +40 生命 |
| 增智剂 | 增智药剂 | 凤羽×2 | +40 魔力 |
| 抗毒剂 | 抗毒药剂 | 蛇的毒牙×2 | 减益抗性（后续扩展） |
| 蛛毒合剂 | 蛛毒药剂 | 八眼巨蛛毒液×2 | 战斗类（后续扩展） |
| 月华剂 | 月华药剂 | 月长石粉×2 | +50 单属性 |
| 曼德拉汤 | 曼德拉汤 | 曼德拉草叶×2 | 大额生命/解除异常 |
| 全能剂 | 全能药剂 | 曼德拉草叶+月长石粉 | 高级全能（稀有） |

- 产出均为一次性效果药，进背包、`/使用` 生效，**商店买不到**。

### 3.3 `/魔药` 命令族
- `/魔药 配方`：查看当前窗口可用配方（含材料消耗与成功率提示）。
- `/魔药 酿造 <配方id>`：消耗 2 材料 + 10 精力 + 30 分钟（复用时间推进机制），按成功率判定产出。

### 3.4 酿造成功率（按魔药学属性分档）
- 魔药学 ≥70：90%
- 魔药学 50~69：75%
- 魔药学 <50：60%
- 失败：**不退还材料**，但给少量熟练度（如 +5 魔药学经验），缓解挫败感。

## 四、数据层改动（Player 新增 3 字段）
- `potionBrewCounts: Map<String,int>`：各配方累计酿造次数（成就依据）
- `potionBrewed: Set<String>`：已酿造过的配方 id（防重复/成就）
- `potionWindowReward: int`：当前窗口奖励领取标记（记档防重，复用节庆模式）
- 存档 21 → 27（与决斗社季度赛 5 字段合计 8 字段；同批实施则 21 → 29）

## 五、实现步骤（批次 A-D）
1. **批次 A（数据层）**：Player 新增 3 字段 + 存档读写 + 迁移（progression_fix_test 同步 +3）。

4. **批次 D（测试）**：窗口判定/材料扣减/成功率/产出入包/窗口奖励防重/成就/存档往返。

## 六、风险与边界
- **行为不变红线**：不动现有 4 种效果药的商店购买与生效逻辑；`/使用` 链路零改动。
- **限时就是限时**：窗口外配方不可见不可酿；跨学期不保留配方（防囤积破坏节奏）。
- **防刷**：受材料获取速度天然限制（禁林采集）+ 每窗口每配方可酿造次数上限（如 3 次）。
- **与 UI 无关**：纯玩法层，不触碰本轮 UI 收敛工作区。
