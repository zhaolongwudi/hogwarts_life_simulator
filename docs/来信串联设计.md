# 来信串联 · 设计预研（2026-09-22）

> 状态：设计预研（未实现）｜ 来源：规划文档第二梯队
> 「来信 → 社团 / 来信 → 羁绊」：P13 的信可以为 P14 社团牵线（社长来信拉你入社），或为 P11 羁绊送好感。

## 一、需求来源

`docs/工作思路与后续规划.md` 第二梯队：
> **来信 → 社团 / 来信 → 羁绊**：P13 的信可以为 P14 社团牵线（社长来信拉你入社），
> 或为 P11 羁绊送好感。

## 二、现状勘察（2026-09-22 核实）

### 2.1 来信系统（P13，mixin_letter.dart / letter_data.dart）
- **三类来信**（`LetterKind`）：
  - `friendship` 友情来信：门槛低、会重复，随好感出现，暖场。
  - `rivalry` 敌对来信：由怨气对手寄来，会挖苦。
  - `milestone` 羁绊里程碑来信：好感跨关键门槛各演一次（演过不重播）。
- **数据模型**（letter_data.dart:52-79）：
  - `LetterDef`：id / kind / senderId（可指定寄信人，null=按品格挑）/ minAffection / maxAffection。
  - `LetterEffect`：senderAffection / galleons / housePoints / reputationDim / reputationValue（口径对齐奇遇/羁绊）。
  - `LetterReply`：title（回信选项）/ text（寄信人回应）/ effect。
- **触发**（mixin_letter.dart:104-154）：`maybeTriggerLetter`——milestone 优先（未收过），friendship/rivalry 按好感/怨气挑选；命中后 `pendingLetterId` 进入「待回信」，下一回合玩家可回信。
- **回信结算**（mixin_letter.dart:176-273）：按回信选项给 `LetterEffect`，清 `pendingLetterId`。

### 2.2 现有缺口：来信不牵线
- 现有来信只给好感/加隆/学院分/声望，**不能把玩家引向社团或羁绊**。
- 「社长来信拉你入社」「羁绊预热信」两种串联场景完全缺失。

## 三、方案设计

### 3.1 核心思路：让来信成为关系的"引线"
> **两类新信：社长邀请信（来信→社团）+ 羁绊预热信（来信→羁绊），把 P13 从"暖场"升级为"牵线"。**

### 3.2 来信→社团：社长邀请信
- **场景**：玩家尚未加入某社团，且与该社 attendee（含社长）好感达标时，社长亲自来信。
- **实现**（不新增 LetterKind，扩展 friendship 信 + senderId 指定）：
  - 新增 `kLetters` 条目：`kind: friendship`、`senderId: <社长id>`、`minAffection: 20`（入社门槛前）。
  - 信文：社长以同好口吻邀请（「听说你也爱在球场泡到天黑——来魁地奇队吧」）。
  - 回信选项：
    - 「好，我加入」→ 触发 `joinClub(clubId)` 入社（复用现有入社链路），好感 +5。
    - 「我再想想」→ 婉拒，好感 +2（不触发入社）。
- **入社后**：该社长信不再出现（已入社判定跳过），与同好注入设计（16d）形成闭环。

### 3.3 来信→羁绊：羁绊预热信
- **场景**：玩家与某 NPC 好感接近 P11 小剧场门槛（`arc.startAffection - 10` 区间）时，收到对方来信。
- **实现**（扩展 milestone 信触发条件）：
  - 现有 milestone 信是「好感跨过门槛后各演一次」；预热信在其**之前**触发。
  - 新增 `kLetters` 条目：`kind: milestone`、`senderId: <羁绊对象>`、`minAffection: startAffection - 10`（需数据层按 arc 动态算或预置）。
  - 信文：对方主动提起你们之间的共同记忆（复用奇遇/羁绊文本素材），为小剧场暖场。
  - 回信结算：好感 +3，且**标记「预热已读」**——P11 触发时首幕文案可引用这封信（跨系统钩子）。
- **防重**：预热信演过不重播（复用 milestone 的 `received.contains` 去重）。

### 3.4 与四社小玩法/同好注入的联动
- 社长邀请信 ↔ 同好注入（16d）：入社好感 +5 与社长信 +5 叠加 → 入社仪式感更强。
- 羁绊预热信 ↔ P11：预热 → 小剧场 → 里程碑信，形成「预热→高潮→回响」三段式关系弧线。

## 四、数据层改动
- **零新增 Player 字段**：复用 `letters`（已收信）、`pendingLetterId`（待回信）、`received`（milestone 去重）。
- 可选：`LetterDef` 增加 `String? clubId` 字段（社长信关联社团，默认 null）——数据层小改。
- 存档版本不变（21），无迁移成本（可选字段 readInt/readString fallback null）。

## 五、实现步骤（批次 A-D）
1. **批次 A（数据层）**：`LetterDef` 增加 `clubId`（可选）；`kLetters` 新增 2 类信（社长邀请 ×4 社、羁绊预热 ×3 条示例）。
2. **批次 B（来信→社团）**：`maybeTriggerLetter` 增加「未入社 + 好感达标 → 社长信」分支；回信「加入」选项触发 `joinClub`。
3. **批次 C（来信→羁绊）**：milestone 触发增加预热区间（`startAffection - 10`）；回信结算 +3 好感 + 预热标记。
4. **批次 D（测试）**：社长信触发条件/入社跳转/婉拒分支/预热区间/防重/存档往返。

## 六、风险与边界
- **行为不变红线**：不动现有三型来信的触发与结算；只新增信条目 + 一个可选 `clubId` 字段。
- **不抢戏**：社长信仅限未入社玩家（已入社自动跳过）；预热信低频（仅接近门槛时一次）。
- **与 UI 无关**：纯玩法层，不触碰本轮 UI 收敛工作区。
