### 2.2 现有比赛玩法（mixin_play.dart:871-1031）
- `/魁地奇 比赛`：每周一次（`qLastWeek == gameWeek` 去重）、耗 20 精力、推进 2 小时、`qMatches++`。
- 实力公式：`skill = qSkill + (flying-50)~/3 + (reaction_time-50)~/5 + 扫帚flying加成`。
- 胜负：`myScore = 90 + skill~/2 + rand(31)` vs `oppScore = 70 + rand(81)`。
- 胜：`qWins++`、战斗声望+6、社交+4、学院杯+30、奖金 15 加隆、成就 `first_quidditch_win`。
- 负：学院杯+5、社交+2、辛苦费 5 加隆。
- 赛后：`qSkill +1~2`（clamp 0~100）。

## 三、方案设计

### 3.1 核心思路：训练 → 比赛联动（周常循环）
现有比赛是"点一下就出结果"的孤立事件，训练玩法把它变成周常循环：
> **每周节奏：训练（2 次）→ 状态加成 → 比赛（1 次）→ 排名成长**

训练不是孤立的刷属性，而是为比赛服务的准备动作——训练后本周内比赛有临时加成，让"练了再打"有可感知收益。

### 3.2 `/魁地奇 训练` 命令
- `/魁地奇 训练`：开始一次位置专项训练。
  - 消耗：10 精力 + 30 分钟（复用 `advanceTimeForAction`）。
  - 周上限：每周 2 次（`qTrainWeek` 计数，周一重置——复用 `gameWeek` 变化判定，同 `qLastWeek` 模式）。
  - 效果：`qSkill +1`（clamp 0~100）+ 位置对应属性小幅成长。
- 按位置分训练项目（复用 `qPosition`）：
  - 找球手：金探子扑抓训练 → `reaction_time +1`
  - 追球手：鬼飞球投射训练 → `flying +1`
  - 守门员：球门扑救训练 → `reaction_time +1`
  - 击球手：游走球击打训练 → `flying +1`
- 训练叙事复用 P8 模板：每个位置 2 套训练文案（`kQuidditchTrainMoments`），经 `fillQuidditchTemplate` 填充，保证文风一致。

### 3.3 训练 → 比赛联动（关键机制）
- 本周内每完成 1 次训练，比赛实力公式获得 `+3 skill`（周内可叠加，上限 2 次即 +6）。
- 实现方式：比赛结算段读取 `qTrainWeek`（本周训练次数），`skill += qTrainWeek * 3`。
- 收益感知：训练后比赛「更可能赢」→ 学院杯/声望/奖金收益 → 训练有意义。
- 边界：训练加成仅限本周比赛；下周清零（`qTrainWeek` 随周数重置）。

### 3.4 成就与长期目标
- 新增成就 `training_master`「训练大师」：累计训练 10 次（`qTrainTotal >= 10`）。
- 新增成就 `weekly_champion`「周冠」：单周训练 2 次且当周比赛获胜（联动验证）。
- 累计训练次数同时作为社团 rank 之外的第二条成长线，与 `broom_*` 任务互补。

## 六、风险与边界
- **行为不变红线**：不动 `/魁地奇 比赛` 现有结算与奖励；`qSkill` 成长节奏不变（训练 +1 与比赛 +1~2 并存，幅度克制）。
- **防刷**：周 2 次上限天然防刷；比赛仍每周 1 次（`qLastWeek` 去重不动）。
- **数值克制**：训练加成上限 +6 skill（对比 myScore 波动 ±30），不会碾压比赛结果。
- **与 UI 无关**：纯玩法层，不触碰本轮 UI 收敛工作区。
