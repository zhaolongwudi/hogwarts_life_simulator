## 二、现状勘察（2026-09-22 核实）

### 2.1 快讯社社团（club_data.dart:338-360, 579-615）
- `ClubDef(id: 'quip')`，tagline「把城堡里的新鲜事写进每一份快讯」。

  - `quip_exclusive` 独家头条：6 轮 / 70 分 / creativity+8

### 2.2 P10 奇遇池（happenstance_data.dart / mixin_happenstance.dart）
- **数据规模**：`kHappenstances` 共 10 条奇遇。
- **数据模型**：`HappenstanceDef`（季节/地点/年级过滤 + weight 权重 + 2~4 个 `HappenstanceOutcomeDef` 选项）。
- **效果模型**：`HappenstanceEffectDef`（声望/学院分/加隆/精力/NPC 好感/物品，对齐节庆口径）。
- **触发机制**（mixin_happenstance.dart:60-92）：`maybeTriggerHappenstance`——启用中、无进行中奇遇、冷却已过、加权抽中（`totalWeight` 区间掷骰）；`triggerHappenstance` 输出触发文案。
- **交互节奏**：触发当回合给 2~4 选项 → 下一回合选定 → 结算（记档去重后不重复）。

### 2.3 学期切换锚点（mixin_systems.dart:684-688）
- `worldState.term`：`'first'`（9-12月）/ `'second'`（1-6月）/ `'summer'`（7-8月）。
- 学期边界 = 头版事件「赛季末」的天然结算点。

## 三、方案设计

### 3.1 核心思路：把"城堡大事"变成快讯社的可玩入口
快讯社现有玩法是「采访/写稿打卡」（`quip_*` 任务），头版事件把它升级为：
> **每学期末，从本学期发生的大事里选一件做"头版报道"，玩家主导选题与报道角度，产出专属头版事件。**

头版不是凭空生成，而是**从玩家本学期的真实经历中取材**——报道自己参与过的事，形成「经历 → 记忆 → 头版」的闭环。

### 3.2 素材来源：复用 P10 奇遇池（两段式改造）
- 奇遇池 10 条奇遇自带「季节 + 地点 + 年级」过滤与两段式交互，天然适配"学期内大事"。
- 复用方式（不侵入 P10 主链路）：
  1. 新增 `kHeadlinePicks`：从奇遇池中筛选适合上头条的条目（按 `season` 标签匹配当前学期）。
  2. 头版事件 = 「已完成奇遇的年度回顾」+「未触发奇遇的选题猎取」双通道：
     - **回顾通道**：学期内玩家触发并完成的奇遇，可被选为头版素材（有真实记忆背书）。
     - **猎取通道**：学期末未完成的奇遇选题池，玩家可主动"蹲一个"（复用冷却期后的再次触发）。

### 3.3 `/快讯 头版` 命令
- `/快讯 头版`：查看本学期可报道的候选素材（已完成奇遇 + 可猎取选题）。
- `/快讯 报道 <素材id>`：选定素材 + 报道角度（2~3 个角度选项：现场直击/深度调查/人情故事，复用奇遇选项交互模式）。
- 结算：按角度给不同效果（对齐 `HappenstanceEffectDef` 口径）：
  - 现场直击 → social + 学院分
  - 深度调查 → logic + 声望
  - 人情故事 → NPC 好感 + social

### 3.4 赛季末结算与奖励
- 学期末（term 切换点，mixin_systems.dart:684-688 前后）触发一次头版机会。
- 奖励三档（按报道质量/选择角度）：
  - 普通报道：快讯社积分 +20、social+2
  - 深度报道：快讯社积分 +35、logic+3、社交声望+3
  - 独家头条：快讯社积分 +50、creativity+4、战斗/社交声望+5、全校流传（NPC 好感若干）
- 头版奖励领取记档防重（复用节庆 `记档防重` 模式）。

### 3.5 年度快讯回顾（赛季末汇总）
- 学期末头版结算时，输出一份「年度快讯回顾」：罗列本学期玩家完成的关键事件（奇遇标题 + 结局摘要），汇成一份可读的学期报纸。
- 与规划文档「奇遇结果的长期痕迹」（P10 结局沉淀为角色档案条目）方向一致，为 P14 声望与终章留钩子。

## 四、数据层改动（Player 新增 2 字段）
- `headlineSeason: int`：本学期头版报道标记（防重复，学期切换重置）
- `headlineCount: int`：累计头版报道次数（成就依据）
- 存档 21 → 29（决斗社 5 + 魔药部 3 + 魁地奇 2 + 快讯 2 = 12 字段；同批实施则 21 → 33）

## 五、实现步骤（批次 A-D）
1. **批次 A（数据层）**：Player 新增 `headlineSeason`/`headlineCount` + 存档读写 + 迁移（progression_fix_test 同步 +2）。
2. **批次 B（素材池）**：新增 `kHeadlinePicks` 素材映射（关联奇遇 id + 报道角度定义），从 `kHappenstances` 筛选；`/快讯 头版` 路由（素材列表展示）。
3. **批次 C（报道结算）**：`/快讯 报道 <素材id> <角度>`；按角度结算效果；学期末触发头版机会（term 切换点挂钩）；年度快讯回顾输出。
4. **批次 D（测试 + 成就）**：素材筛选/角度结算/学期重置/防重领取/成就/存档往返。

## 六、风险与边界
- **行为不变红线**：不动 P10 奇遇池主链路（`maybeTriggerHappenstance`/`triggerHappenstance` 零改动）；只新增 `kHeadlinePicks` 只读映射。
- **防刷**：每学期仅 1 次头版机会；素材受限于已完成奇遇（真实经历背书，天然防刷）。
- **与 UI 无关**：纯玩法层，不触碰本轮 UI 收敛工作区。
