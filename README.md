# ⚡ 霍格沃兹人生模拟器 · Hogwarts Life Simulator

> **一个 AI 驱动的魔法世界人生模拟器** — 你不是"大难不死的男孩"，你只是这个世界里，一个普通又独一无二的人。

在魔法世界里活一次：去霍格沃茨上学，结识朋友与恋人，从事你喜欢的职业，选择自己的立场。**没有强制主线，没有主角光环，世界自己在运转，你只需要做你自己。**

## ✨ 核心特色

### 🌍 世界不因你而停转
霍格沃茨的学生也在上课、考试、恋爱、吵架；魔法部每天在开会；对角巷商铺开张或倒闭；黑巫师不会等你准备好了才行动。学年晋升，学生毕业离校，时代事件按时间线推进——**玩家不干预，世界照样转**。

### 🤖 真正的自由行动
没有预设剧情分支。想做什么就输入什么——翘课去霍格莫德、研究黑魔法、跟教授吵架、向喜欢的人表白、开一家自己的店铺……系统不会告诉你"不能做什么"，只会告诉你"做了之后会发生什么"。

### 💕 真正"活"着的 NPC
每个角色有自己的性格、日程、目标和人际关系。教授按课表出现在教室，魁地奇队长在球场训练，有人会主动追求你，也有人因你的背叛而永远记恨。还能给 NPC 写信、看他们之间的八卦传闻。

### 🧬 深度人生系统
| 系统 | 说明 |
|---|---|
| 💀 **死亡与坏结局** | 决斗/禁林战败可能致死，死亡不可逆；黑化（黑魔法声望压过道德）会被终章定性为「被黑暗吞没的人」 |
| 💼 **毕业后职业** | 傲罗/圣芒戈治疗师/魔法部/记者/职业魁地奇/诅咒破解师/魔药大师……入职要看 O.W.L/N.E.W.T 成绩+属性+声望，每年九月发薪晋升 |
| 🐺 **阿尼马格斯** | 研习→训练→满月夜尝试→魔法部登记，形态与人格关联，失败有真实代价 |
| ✨ **守护神** | 10 种形态与人格/学院/信念关联，情绪稳定是召唤的关键 |
| 📝 **考试结算** | 8 门必修 O/E/A/P/D/T 六级，学年期末 + 五年级 O.W.L + 七年级 N.E.W.T 真实结算 |
| 📅 **周计划** | `/计划 学习/社交/魁地奇/调查/放松/打工`，批量推进一周 |

## 🧠 配置 AI 引擎（首次使用必看）

剧情由大语言模型实时生成，需要准备一个 API Key。支持 4 家服务商：

| 服务商 | 说明 |
|--------|------|
| **DeepSeek** | 国产模型，剧情生成质量好，价格便宜 |
| **智谱 AI** | 有免费额度，适合新手尝试（glm-4.7-flash） |
| **Agnes** | 响应快，适合 NPC 聊天场景（agnes-2.5-flash 有免费） |
| **SenseNova 商汤** | 稳定，适合摘要和轻量任务 |

**配置步骤：**
1. 打开游戏 → 右下角「设置」
2. 选择 AI 提供商 → 填入 API Key → 保存（Key 加密存储在本机）
3. 可选：为不同场景绑定不同模型（如"主剧情用 DeepSeek，NPC 聊天用 Agnes"）
4. 支持为同一提供商配置多个 API Key，自动负载均衡和限流熔断
5. 返回首页 → 开始游戏

## 🎮 玩法总览

### 🏫 学生生活
分院 → 选课 → 上课互动 → **考试成绩（O.W.L./N.E.W.T. 真实结算）** → 作业 → 魁地奇训练 → 学年晋升直至毕业

### 🌍 地图探索
- **四大区域**：霍格沃茨城堡、伦敦、住宅区、霍格莫德村
- **对角巷**：奥利凡德魔杖店、丽痕书店、古灵阁银行、韦斯莱魔法把戏坊……
- **翻倒巷**：黑魔法商店，进去之前想清楚
- 地图层级导航，每个地点有专属背景氛围

### 💬 NPC 关系
好感度系统（陌生 → 认识 → 友好 → 暧昧 → 亲密 → 恋爱）· NPC 主动约会、表白、吃醋 · 背叛永不遗忘 · 世界传闻八卦系统（30 天自然衰减）· 拉郎配撮合

### 💰 经济与职业
加隆/西可/纳特货币 · 古灵阁存取 · 学生打工 · **毕业后正式职业**（成绩门槛 + 年结晋升）· 商店买卖 · 周计划打工

### 📱 魔法手机
魔法通讯 · 魔法论坛（看八卦、发帖）· 日记（自动记录+手写+重播回顾）· 姻缘红娘 · 相册回忆（CG 画廊、时间线、收藏）· 找工作、地图、背包、存档管理、人生目标

### 🏆 成就与收藏
33 项成就 · 33 张 CG（相遇、暧昧、深情、表白、心碎……剧情自动解锁）· 多结局系统 · 人生终章报告（含伤疤与一生回望）

### 🧪 扩展玩法
- **物品使用**：食品、药水、书籍真实可用（饱食、疗伤、回魔、学咒）
- **宠物互动**：喂食、玩耍、训练提升羁绊；九尾灵狐羁绊 ≥60 化为人形
- **装备穿戴**：袍子/帽子/扫帚/饰品四槽位，影响属性与施法成功率
- **魁地奇**：每周一场，胜场为学院赢得 30 分学院杯积分
- **巫师决斗**：施法成功率 = 熟练度 × 环境 × 心理 × 装备
- **禁林探险**：遭遇神奇生物、采材料、捡加隆，危险随年级逐步开放
- **魔法生物图鉴**：记录 12 种神奇生物，集齐解锁学者成就
- **支线委托板**：收集/讨伐/培养三类委托，禁林与宠物自动推进进度
- **学院杯**：魁地奇、决斗、委托、探险为学院攒分，学年末结算排名
- **传承局**：让下一代接过你的故事

## ⚡ 游戏指令（60+）

剧情输入框输入指令快速访问系统功能。指令已全部收录进**指令中心面板**（底部终端按钮 `>_` 打开）：按分组模块化展示、实时搜索、一键执行，作弊指令默认折叠。

| 分组 | 指令 |
|------|------|
| **基础信息** | `/状态` `/时间` `/地图` `/通知` `/世界演化` `/帮助` |
| **关系情感** | `/恋爱阶段` `/恋爱等待` `/关系网络` `/声望` `/送信` `/写信` `/表白` `/拉郎配` |
| **学业成长** | `/课程 成绩` `/计划 学习/社交/魁地奇/调查/放松/打工` `/阿尼马格斯` `/守护神` |
| **玩法活动** | `/魁地奇` `/决斗` `/禁林 探险` `/图鉴` `/委托` |
| **物品宠物** | `/使用` `/装备` `/卸下` `/宠物` |
| **世界结局** | `/职业 列表/选择/状态/辞职` `/结局` `/传承` `/联动` |
| **作弊（默认折叠）** | `/cheat 列表` — 25+ 子命令（好感/熟练度/加隆/世界线/知晓/剧情/无敌/全知/配对/新NPC/收藏/成就…） |

> 💡 想发送以 `/` 开头的**普通内容**？用 `//` 开头即可（如 `// 我捡起地上那本书`）。

## 🛡️ 隐私说明

- **所有数据都在本地**：API Key 加密存储，存档自动备份 + 损坏回滚
- **不收集任何用户数据**，无远程上报，无后台统计

## 👨‍💻 开发相关

### 技术栈
- **框架**：Flutter 3.16+ / Dart 3.2+
- **状态管理**：Provider
- **本地存储**：JSON 文件 + flutter_secure_storage 加密
- **AI 接入**：DeepSeek / 智谱 / Agnes / SenseNova，多 Key 负载均衡 + 熔断 + 限流

### 构建 APK
```bash
flutter build apk --release
```

### CI 自动构建
推送到 `main` 分支后，GitHub Actions 自动执行：
1. `flutter analyze` 代码检查（0 error 门禁）
2. 全量测试套件回归（1254+ 项）
3. 构建 Release APK，上传至 nightly.link 和 GitHub Releases

### 存档兼容
存档 JSON 含 `_saveVersion` 版本号字段，读取时自动跨版本迁移，保证旧档不丢。
