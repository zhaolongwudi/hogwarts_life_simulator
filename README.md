# 哈利·波特 · 魔法纪元

> 一个 AI 驱动的魔法世界人生模拟器 — 你不是"大难不死的男孩"，你只是这个世界里，一个普通又独一无二的人。

在魔法世界里活一次：去霍格沃茨上学，结识朋友与恋人，从事你喜欢的职业，选择自己的立场。没有强制主线，没有主角光环，世界自己在运转，你只需要做你自己。

---

## ✨ 特色

**🌍 世界不因你而停转** — 霍格沃茨的学生也在上课、考试、恋爱、吵架；魔法部每天在开会；对角巷商铺开张或倒闭；黑巫师不会等你准备好了才行动。学年晋升，学生毕业离校，世界一年年往前走。

**🤖 真正的自由行动** — 没有预设剧情分支。想做什么就输入什么——翘课去霍格莫德、研究黑魔法、跟教授吵架、向喜欢的人表白、开一家自己的店铺……系统不会告诉你"不能做什么"，只会告诉你"做了之后会发生什么"。

**💕 真正"活"着的 NPC** — 每个角色有自己的性格、日程、目标和人际关系。教授按课表出现在教室，魁地奇队长在球场训练，有人会主动追求你，也有人因你的背叛而永远记恨。还能给 NPC 写信、看他们之间的八卦传闻。

**📖 五个时代可选**

| 时代 | 年份 | 氛围 |
|------|------|------|
| 邓布利多时代 | 1892 | 魔法世界的黄金年代 |
| 亲世代 | 1971 | 掠夺者们的校园时光 |
| 一战末期 | 1976 | 战争阴影下的人人自危 |
| 子世代 | 1991 | 哈利入学的经典时期 |
| 战后重建 | 2020 | 和平年代的新生活 |

**🧬 开局稀有特质** — 创建角色时抽取稀有度不同的开局特质（软保底机制），影响属性加成和叙事走向。

## 🧠 配置 AI 引擎（首次使用必看）

剧情由大语言模型实时生成，需要准备一个 API Key。支持 4 家服务商：

| 服务商 | 说明 |
|--------|------|
| **DeepSeek** | 国产模型，剧情生成质量好，价格便宜 |
| **智谱 AI** | 有免费额度，适合新手尝试（glm-4.7-flash） |
| **Agnes** | 响应快，适合 NPC 聊天场景（agnes-2.5-flash 有免费） |
| **SenseNova 商汤** | 稳定，适合摘要和轻量任务 |

**配置步骤：**
1. 打开游戏 → 右下角「设置」
2. 选择 AI 提供商 → 填入 API Key → 保存（Key 加密存储在本机）
3. 可选：为不同场景绑定不同模型（如"主剧情用 DeepSeek，NPC 聊天用 Agnes"）
4. 支持为同一提供商配置多个 API Key，自动负载均衡和限流
5. 返回首页 → 开始游戏

## 🎨 玩法

### 🎓 学生生活
分院、选课、上课、课堂互动、考试、作业、魁地奇训练 · 四大学院 · 学年晋升直至毕业 · 开局稀有特质

### 🌍 地图探索
**四大区域**：霍格沃茨城堡、伦敦、住宅区、霍格莫德村
**对角巷**：奥利凡德魔杖店、丽痕书店、古灵阁银行、韦斯莱魔法把戏坊……
**翻倒巷**：黑魔法商店，进去之前想清楚
地图层级导航，每个地点有专属背景氛围

### 💬 NPC 关系
好感度系统：陌生 → 认识 → 友好 → 暧昧 → 亲密 → 恋爱 · NPC 主动约会、表白、吃醋 · 背叛永不遗忘 · 世界传闻八卦系统

### 💰 经济与职业
加隆/西可/纳特货币 · 古灵阁存取 · 打工赚钱：魔法部临时文员、霍格莫德村服务生、对角巷采购助理、古灵阁金币搬运工、神奇动物照看员 · 商店买卖

### 📱 魔法手机
魔法通讯（只显示已认识的人） · 魔法论坛（看八卦、发帖） · 日记（自动记录+手写+重播回顾） · 姻缘红娘 · 相册回忆（CG 画廊、时间线、收藏） · 找工作、地图、背包、存档管理、人生目标

### 🏆 成就与收藏
33 项成就 · 33 张 CG（相遇、暧昧、深情、表白、心碎……剧情自动解锁） · 多结局系统

### 🧪 扩展玩法
- **物品使用**：食品、药水、书籍真实可用（饱食、疗伤、回魔、学咒）
- **宠物互动**：喂食、玩耍、训练提升羁绊；九尾灵狐羁绊≥60 化为人形
- **装备穿戴**：袍子/帽子/扫帚/饰品四槽位，影响属性与施法成功率
- **魁地奇**：每周一场，胜场为学院赢得 30 分学院杯积分
- **巫师决斗**：施法成功率 = 熟练度 × 环境 × 心理 × 装备
- **禁林探险**：遭遇神奇生物、采材料、捡加隆，危险随年级逐步开放
- **魔法生物图鉴**：记录 12 种神奇生物，集齐解锁学者成就
- **支线委托板**：收集/讨伐/培养三类委托，禁林与宠物自动推进进度
- **学院杯**：魁地奇、决斗、委托、探险为学院攒分，学年末结算排名

## 👨‍💻 开发相关

### 技术栈
- Flutter 3.16.0+ / Dart 3.2.0+
- 状态管理：Provider
- 本地存储：JSON 文件 + flutter_secure_storage 加密

### 构建 APK
```bash
flutter build apk --release
```

### CI 自动构建
推送到 `main` 分支后，GitHub Actions 自动执行：
1. `flutter analyze` 代码检查
2. 构建 Release APK
3. 上传至 nightly.link 和 GitHub Releases

### 存档兼容
存档 JSON 含 `_saveVersion` 版本号字段，读取时自动跨版本迁移，保证旧档不丢。
