# 哈利·波特·魔法纪元

> 魔法世界沙盘 · 超高自由度人生模拟器 · 多模型 AI 驱动的文字冒险游戏

你不是"大难不死的男孩"。你只是这个魔法世界里出生的一个人。可以成为巫师、傲罗、治疗师、魔药师、魁地奇球员、魔法部官僚、霍格沃茨教授、魔杖匠人、记者、商人、古灵阁解咒员、龙学家、麻瓜联络员、黑巫师、凤凰社成员、食死徒、政客、作家、旅店主、普通巫师。甚至可以一辈子都没有拥有过一根真正属于自己的魔杖。这同样是一种完整人生。

本模拟器以《哈利·波特》原著七部小说为正典。原著世界观、设定、人物、事件、时间线优先于一切自定义、随机推演与剧情扩展。

## 核心特性

### 📜 融合版世界观系统
- **玩家非天命主角**：世界不围绕玩家运转，其他学生也在上课，其他人的家庭同样在发生事情
- **最高原则**：玩家不是大难不死的男孩，不上课时其他学生也在上课，暑假时其他人家庭同样在发生事情
- **四大时代**：邓布利多时代（1892）、亲世代（1971）、一战末期（1976）、子世代（1991）、战后（2020）
- **叙事风格**：小说化叙事，包含感官细节、人物心理、环境描写
- **月度世界演化**：世界不因玩家停转，魔法部/黑巫师/霍格沃茨/神奇生物/经济动态自动结算
- **防主角光环**：玩家没有默认传奇血统、死亡圣器、预言、强大魔杖
- **防过度热闹**：禁止每月都有黑魔头/魂器/死亡圣器/魔法战争

### 🎭 角色创建系统
- **5个时代**：邓布利多时代 / 亲世代 / 第一次巫师战争 / 子世代 / 战后重建
- **多种血统**：纯血/混血/麻瓜出身/特殊血脉
- **深度个性化**：姓名、性别、性向、外貌、家族背景、童年经历、性格特质、信仰价值观、魔杖、宠物、好友
- **九尾狐宠物**：东方神话背景，可化人形，女性化，倾国倾城，完全听命于玩家

### 🌍 世界探索
- **四大区域地图**：霍格沃茨城堡、伦敦、住宅区、霍格莫德村
- **对角巷子地图**：真实魔法店铺
- **翻倒巷子地图**：黑魔法地点
- **层级导航**：大世界 → 子区域 → 更深层子区域，面包屑路径

### 🤖 AI 驱动叙事
- **支持多模型**：DeepSeek、智谱AI（Zhipu）、Agnes-2.5-flash、SenseNova·商汤日日新
- **多模型路由**：支持按场景绑定不同AI提供商（主剧情/摘要/NPC聊天）
- **自定义行动**：自由输入想法，AI即时响应，系统不限制行动只计算后果
- **五色富文本渲染**：人名（金）、对话（蓝）、地点（绿）、物品（紫）、旁白（灰）自动高亮
- **Token优化**：滑动窗口截断、关键状态按需注入、系统提示词压缩，每回合800-1500 token
- **多提供商降级**：主提供商失败时自动降级到备用提供商

### 📱 手机系统
| 应用 | 功能 |
|------|------|
| 魔法通讯 | AI驱动NPC对话，智能关系标签 |
| 魔法论坛 | 5个分类板块，点赞/发帖交互 |
| 我的日记 | 系统自动生成+手写日记，心情选择 |
| 对角巷 | 魔法商店购物系统，加隆货币交易 |
| 世界地图 | 四大区域+子地图层级导航 |
| 平行世界 | "如果"小剧场，支持自定义 |
| 姻缘红娘 | NPC智能匹配算法 |
| 找工作 | 职业系统，赚取加隆（5个岗位） |
| 相册回忆 | 章节时间线、收藏、CG画廊 |
| 存档管理 | 自动存档+手动存档 |
| 我的背包 | 物品栏管理 |

### 💕 恋爱系统
- **NPC主动表白**：基于好感度、关系阶段、浪漫事件计数和持续时间的多条件触发
- **表白叙事**：根据NPC人格生成不同风格的表白
- **好感沉淀**：首周好感上限+30，防止快速刷好感
- **记仇机制**：背叛后好感不可超越历史最高值
- **关系阶段**：陌生 → 认识 → 友好 → 暧昧 → 亲密 → 恋爱

### 🏆 成就与CG系统
- **20项成就**：覆盖初始事件、社交、经济、战斗、收藏等多个维度
- **36张CG**：7大章节（相遇、暧昧、深情、珍贵、表白心碎、拉郎配、骨科）
- **自动解锁**：根据好感度、事件自动触发CG和成就解锁

### 🛡️ 防崩坏机制
- **资源值钳制**：生命、魔力、精神力等属性自动保持在合理范围
- **跨系统检查**：属性、学院四维、世界线变动率、NPC好感、恋爱状态、时间、货币一致性检查
- **声望自动修正**：声望越界时自动修正
- **背包清理**：物品超过上限自动清理
- **时代一致性**：存档与当前设置的时代检测

### 🎨 NPC生成系统
- **8种人格模板**：勇敢型/智慧型/温柔型/野心型/忠诚型/神秘型/幽默型/叛逆型
- **个性化外貌**：按学院生成不同外貌描述
- **随机背景故事**：每个人格都有3种以上的背景故事选项
- **个人目标**：按人格和学院生成NPC的个人目标
- **日程系统**：按学院生成NPC的每日日程安排
- **声望特征**：按人格生成分布式声望
- **已知信息**：按人格生成NPC的已知知识

## 快速开始

### 环境要求
- [Flutter SDK](https://docs.flutter.dev/get-started) >= 3.16.0
- JDK 17（用于 Android 构建）
- 至少一个 AI 提供商的 API Key

### 安装运行

```bash
git clone https://github.com/zhaolongwudi/hogwarts_life_simulator.git
cd hogwarts_life_simulator
flutter pub get
flutter run
```

### 配置 AI

首次运行后，在 **设置** 页面配置 AI 引擎：
1. 选择 AI 提供商（DeepSeek / 智谱AI / Agnes / SenseNova）
2. 填入 API Key
3. 选择模型
4. 配置场景路由（可选）：为不同场景绑定不同的AI提供商
5. 开始你的魔法之旅
