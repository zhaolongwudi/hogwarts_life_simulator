# 哈利·波特·魔法纪元

> 魔法世界沙盘 · 超高自由度人生模拟器 · 由多模型 AI 驱动的文字冒险游戏

你不是"大难不死的男孩"。你只是这个魔法世界里出生的一个人。可以成为巫师、傲罗、治疗师、魔药师、魁地奇球员、魔法部官僚、霍格沃茨教授、魔杖匠人、记者、商人、古灵阁解咒员、龙学家、麻瓜联络员、黑巫师、凤凰社成员、食死徒、政客、作家、旅店主、普通巫师。甚至可以一辈子都没有拥有过一根真正属于自己的魔杖。这同样是一种完整人生。

本模拟器默认以《哈利·波特》原著七部小说为正典。原著世界观、设定、人物、事件、时间线优先于一切自定义、随机推演与剧情扩展。

## ✨ 核心特性

### 📜 75章终极世界观系统
- **原著优先级别**：原著明确设定 > 模拟器扩展推演，7条优先级规则锚定正典
- **九大文明支柱**：魔法学校、魔法部、纯血家族、麻瓜社会与保密法、魔法商业、神奇生物生态、黑巫师与黑暗势力、国际巫师社会、预言与神秘事务司
- **五层世界结构**：麻瓜世界 → 巫师社会 → 魔法学校 → 禁地与黑魔法 → 死亡·灵魂·时间
- **八大历史时代**：从霍格沃茨建校到现代巫师社会，每个时代锚定原著事件与人物状态
- **月度世界演化**：每回合自动结算魔法部/黑巫师/霍格沃茨/神奇生物/经济/国际动态，世界不因玩家停转
- **防过度热闹协议**：禁止每月都有黑魔头/魂器/死亡圣器/魔法战争，魔法世界也有大量普通生活
- **防主角光环协议**：玩家没有默认传奇血统、死亡圣器、预言、强大魔杖
- **AI自检系统**：每15轮强制输出剧情快照与人设OOC自检报告
- **终极原则十四条**：原著优先｜自由行动｜魔法有成本｜社会真实｜预言非绝对｜权力流动｜生态平衡｜文明演化｜世界存在未知｜时间不等待｜NPC独立人格｜历史可改变｜死亡真实不可逆｜故事可传承

### 🎭 角色创建系统（十三轮深度设定）
- **8个时代**：霍格沃茨建校早期 / 中世纪猎巫时期 / 格林德沃崛起时代 / 第一次巫师战争 / 第二次巫师战争 / 战后重建时代 / 现代巫师社会 / 自定义
- **11种血统**：麻瓜出身 / 混血巫师 / 纯血旁支 / 神圣二十八族 / 哑炮 / 默然者（高风险）/ 混血媚娃 / 狼人 / 半巨人 / 麻瓜家庭 / 自定义
- **11种出生身份**：普通巫师家庭 / 麻瓜家庭 / 孤儿 / 纯血没落家族 / 纯血豪门 / 魔法部官员家庭 / 傲罗家庭 / 教授家庭 / 古灵阁妖精契约相关 / 圣芒戈治疗师家庭 / 自定义
- **6级魔法资质**：哑炮无魔法天赋 → 普通 → 良好 → 优秀 → 特殊（易容马格斯/蛇佬腔/预言天分/变形天赋/大脑封闭术天赋）→ 随机
- **5种学院倾向**：系统判定 / 格兰芬多 / 斯莱特林 / 拉文克劳 / 赫奇帕奇 / 未入学
- **6种政治倾向**：血统平等 / 纯血保守 / 中立投机 / 凤凰社支持 / 食死徒同情 / 自由独立
- **6种模拟风格**：极度现实 / 经典校园冒险 / 史诗巫师战争 / 黑暗奇幻 / 日常人生 / 混合模式
- **深度个性化**：姓名、性别、性向、外貌、家族背景、童年经历、性格特质、信仰价值观、魔杖（木材·杖芯·长度·弹性）、宠物、好友、剧情起点

### 🌍 世界探索
- **四大区域地图**：霍格沃茨城堡（18地点）、伦敦（9地点）、住宅区（8地点）、霍格莫德村（12地点）
- **对角巷子地图**：16家真实魔法店铺（古灵阁、奥利凡德魔杖店、韦斯莱魔法把戏坊等）
- **翻倒巷子地图**：6个黑魔法地点（博金-博克、黑魔法市集等）
- **层级导航**：大世界 → 子区域 → 更深层子区域，面包屑路径
- **区域危险度**：安全区 → 低危险区 → 中等危险区 → 高危险区 → 极度危险区
- **动态NPC**：14+原著角色，各有独立性格、位置和行为

### 🤖 AI 驱动叙事
- **世界模拟系统**：AI身份为"哈利·波特·魔法纪元·世界模拟系统"，负责维护原著优先级别、魔法、血统、家族、魔法部、霍格沃茨、神奇生物、黑巫师、预言、历史、时间、因果
- **支持多模型**：DeepSeek、智谱AI（Zhipu）、Agnes-2.5-flash
- **三重保障叙事**：结构化解析 → 智能提取 → 兜底生成，确保叙事永不丢失
- **自定义行动**：自由输入想法，AI即时响应，系统不限制行动只计算后果
- **上下文记忆**：AI记住选择和关系变化
- **五色富文本渲染**：剧情中人名（金）、对话（蓝）、地点（绿）、物品（紫）、旁白（灰）自动高亮

## 🚀 快速开始

### 环境要求
- [Flutter SDK](https://docs.flutter.dev/get-started) >= 3.16.0
- JDK 17（用于 Android 构建）
- 至少一个 AI 提供商的 API Key

### 安装运行

```bash
# 克隆项目
git clone https://github.com/zhaolongwudi/hogwarts_life_simulator.git
cd hogwarts_life_simulator

# 安装依赖
flutter pub get

# 运行（需连接设备或模拟器）
flutter run
```

### 配置 AI

首次运行后，在 **设置** 页面配置 AI 引擎：
1. 选择 AI 提供商（DeepSeek / 智谱AI / Agnes）
2. 填入 API Key
3. 选择模型
4. 开始你的魔法之旅

## 📦 构建 APK

### 本地构建

```bash
flutter build apk --release
```

### CI 自动构建

推送代码到 `main` 分支后，GitHub Actions 会自动：
1. **自动递增版本号**（0.0.6 → 0.0.7 → ... → 0.0.10 → 0.1.0）
2. 运行 `flutter analyze` 代码检查
3. 构建 release APK
4. 重命名为 `HogwartLige-{版本号}.apk`
5. 上传为 GitHub Release 资产

下载最新版本：[Releases 页面](https://github.com/zhaolongwudi/hogwarts_life_simulator/releases)
